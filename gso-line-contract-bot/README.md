# GSOリフォーム 契約書LINEボット

LINEグループに投稿された請負契約書の写真を読み取り、「【GSOリフォーム】経営管理帳票」の「入金管理」シートに1行追記して、読み取り結果をグループに返信する。

- 実行環境: Google Apps Script（無料）
- 読み取り: Claude API（claude-opus-5-5、構造化出力）
- 費用目安: 契約書1枚あたり数円。LINE公式アカウント・GAS・Driveは無料枠

## 書き込む列

| 列 | 項目 | 埋め方 |
|---|---|---|
| B | 契約日 | 契約書下部の「日付」欄（空欄なら支払方法の契約締結時） |
| C | 代理店 | 担当者から「LINE連携」シートで変換 |
| D | 担当者 | 請負者欄の担当者サイン。空欄ならLINE投稿者から推定 |
| E | 顧客名 | 注文者氏名。姓と名の間は全角スペースに統一 |
| F | カテゴリ | 工事名称からマスタのカテゴリ一覧に分類 |
| G | 契約金額（税込） | 請負金額（税込） |
| M | 入金予定日 | 支払方法の完工時の日付 |
| O | 入金状況 | 「未入金」固定 |
| Q | 支払通知書 | 「未作成」固定 |
| S | 備考 | 工事名称・場所・電話・工期・Driveの画像リンク・要確認項目 |

A・H・J・K・L の数式列は触らない（新しい行には1つ上の行の数式をコピーする）。

## セットアップ手順

1. **LINE公式アカウント**
   - LINE Developers でプロバイダーを作り、Messaging API チャネルを作成（既存の公式アカウントがあればそれに Messaging API を有効化）
   - LINE Official Account Manager > 設定 > 応答設定: 「応答メッセージ」OFF、「Webhook」ON、「グループ・複数人チャットへの参加を許可する」ON
   - LINE Developers > Messaging API設定 > 「チャネルアクセストークン（長期）」を発行して控える
2. **Anthropic APIキー**
   - console.anthropic.com でAPIキーを発行。月の上限（例: 5,000円）を設定しておく
3. **Googleドライブ**
   - 契約書写真の保存先フォルダ（例: `GSO契約書`）を作り、URLの `folders/` 以降のIDを控える
4. **Apps Script**
   - スプレッドシート「【GSOリフォーム】経営管理帳票」を開き、拡張機能 > Apps Script
   - `Code.gs` の中身を全部貼り付けて保存
   - 左の歯車「プロジェクトの設定」> スクリプト プロパティ に以下を追加
     - `LINE_CHANNEL_ACCESS_TOKEN`
     - `ANTHROPIC_API_KEY`
     - `SPREADSHEET_ID` = `1q9cTqWUhwjcBfwF5-hufukyoQkGJC8kcH0_awnQA8FE`
     - `DRIVE_FOLDER_ID`
   - エディタ上部で関数 `setup` を選んで実行（初回は権限の承認が出る）。「LINE連携」「LINE処理ログ」シートができる
   - デプロイ > 新しいデプロイ > 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」→ デプロイ → ウェブアプリURLを控える
5. **Webhook接続**
   - LINE Developers > Messaging API設定 > Webhook URL にウェブアプリURLを貼り、「Webhookの利用」ON
   - 「検証」ボタンはGASのリダイレクトの都合で失敗することがある。失敗しても実際の投稿は届くので、次のテストで確認する
6. **グループに招待**
   - 契約書が流れているグループに公式アカウントを招待する
   - 契約書を1枚投稿し、30〜60秒以内に読み取り結果の返信が来れば完了
   - 返信が来ない場合は Apps Script の「実行数」でエラーを確認する

## 運用ルール（現場に伝えること）

- 契約書は **表面（1ページ目）を1枚で**、できれば「オリジナル画質」で送る
- 1契約で複数枚送る場合は **同時にまとめて送る**（別々に送ると別契約として扱われることがある）
- 返信に「⚠ 要確認」が付いた項目は投稿者がその場でシートを直す
- 「登録済み」と返ってきたら台帳側の行を確認する。顧客名が違うと表示されたら手入力ミスの可能性が高い
- 担当者が増えたら「LINE連携」シートに 担当者・代理店・LINE表示名 を1行足す

## 既知の制約

- GASはリクエストヘッダーを読めないため、LINEの署名検証ができない。ウェブアプリURLを外部に出さないこと。心配なら `ALLOWED_GROUP_IDS` にグループIDを入れて他からの投稿を無視する
- ボットが参加する前の投稿は読めない
- 手書きの読み取りなので誤読はゼロにならない。返信を人が見る前提の設計

## 動作確認（LINEなしで）

Driveに契約書写真を置き、`testWithDriveFile` 内の `fileId` を書き換えて実行すると、読み取り結果と台帳の重複判定だけをログに出す（シートには書かない）。
