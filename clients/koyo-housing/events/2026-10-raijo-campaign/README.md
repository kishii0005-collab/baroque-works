2. 既存イベント記事を「複製」して新規作成（テーマの書式を維持するため）
3. 本文をコードエディタに切り替え、`post-content.html` を貼り付け
4. 【】の箇所を差し替え（予約フォームURL・画像URL・会場・時間・特典条件）
