## 4. ファイル構成とビルド
- `build.py`：本体。`more.py` → `pages2.py` → `polish.py` の順に exec する。CSS は build.py 内の CSS ＋ `extra.css` を `site.css` に書き出す
- `extra.css`：上書きの CSS。後ろに追記するほど優先される（PASS 4〜8 が今のデザイン）。`:root` の変数は、ページ内の critical CSS に負けるので `html:root{}` で上書きする
- `site.js`：動きの JS（統計のカウントアップは無効化済み）
- `jmap.py`：日本地図（@svg-maps/japan, CC BY 4.0。サイトマップにクレジット記載済み）
- 写真：`img/` のローカル画像が優先、無ければ Unsplash。人物は `img/tanioka*.jpg`・`img/ishii.jpg`（石井さんはスライドから切り出した低解像度。元データが来たら差し替え）
- ビルド：`cd edge-asset && python3 build.py index.html`
